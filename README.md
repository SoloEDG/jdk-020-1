
## 本地启动

```sh
npm run dev
```

## 运行检查

```sh
npm run check
```

覆盖天气的一次性触发、预报保密、除冰保护期、冒险/等待放行、车辆避险与存档校验。

## 天气与放行

- 每班开始时生成一套天气脚本（雷雨 + 低温结冰），实际到达/消散时刻隐藏在预报窗口内。
- 预报只在发布时刻之后出现；雷雨按移动轨迹影响机位与车辆，结冰限制非除冰机位。
- 除冰保护期从除冰**实际完成**时起算；等待推出期间过期，必须重新除冰。
- 临近放行时可二选一：冒险争取窗口（显示成功率与失败损失）或保守等待（显示延误与损失）。
- 暂停、变速、保存/读取、重开页面都不会重复触发同一次天气；已中断的保障保留进度，天气转好也不会自动完成，需要重新派遣。
